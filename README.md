# Sistem Manajemen Siswa

## Deskripsi
Sistem Manajemen Siswa adalah aplikasi berbasis console yang dibuat menggunakan bahasa pemrograman C++. Aplikasi ini digunakan untuk mengelola data siswa secara sederhana dan efisien.

## Fitur
- Menambahkan data siswa
- Menampilkan data siswa
- Memperbarui data siswa
- Menghapus data siswa
- Penyimpanan data menggunakan file
- Menu interaktif berbasis console
- Validasi NIS agar tidak terjadi data duplikat

## Data yang Dikelola
- NIS
- Nama
- Umur
- Jurusan

## Teknologi
- C++
- Struct
- Vector
- File Handling
- CRUD

## Cara Kerja
Program menyediakan menu utama yang memungkinkan pengguna memilih operasi yang ingin dilakukan. Data siswa disimpan secara permanen menggunakan file `siswa.txt`.

## Tujuan
Project ini dibuat untuk menerapkan konsep dasar pemrograman C++, khususnya penggunaan struktur data, fungsi, operasi CRUD, dan file handling.
